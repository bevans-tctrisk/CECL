# Found 5 Dollars — "Barbecue Sauce" shirt print

Darts-board marketing print for the Found 5 Dollars app. If you get it, you get it.

## Files

| File | Purpose |
|------|---------|
| `found5_barbecue_sauce_print_BEVAN_4500x5400.png` | Final print, black background, 4500x5400 (15"x18" @ 300 DPI) |
| `found5_barbecue_sauce_print_BEVAN_transparent.png` | Same art with the black background knocked out, for DTG printing on dark garments |
| `found5_barbecue_sauce_print_source_4500x5400.png` | Original source print (pre-Bevan title) |
| `make_bevan_print.py` | Regenerates both outputs from the source (requires Pillow) |
| `fonts/Bevan-Regular.ttf` | Bevan typeface used for the title |

## Font

The title "Barbecue Sauce" is set in **Bevan** (Vernon Adams / Vaclav Krejci),
licensed under the SIL Open Font License 1.1, obtained from Google Fonts:
https://fonts.google.com/specimen/Bevan

Title ink is cream `RGB(237, 228, 207)` to match the board segments.
